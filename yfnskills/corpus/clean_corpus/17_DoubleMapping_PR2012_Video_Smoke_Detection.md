## Title

<!-- src: S001, S002, S003 — intact -->
A double mapping framework for extraction of shape-invariant features based on multi-scale partitions with AdaBoost for video smoke detection

Feiniu Yuan

Pattern Recognition 45 (2012) 1186–1196. DOI: 10.1016/j.patcog.2011.08.008

## Abstract

<!-- src: S005 — intact -->
Traditional methods for video smoke detection can easily achieve very low training errors but their generalization performances are not good due to arbitrary shapes of smoke, intra-class variations, occlusions and clutters. To overcome these problems, a double mapping framework is proposed to extract partition based features with AdaBoost. The first mapping is from an original image to block features. A feature vector is presented by concatenating histograms of edge orientation, edge magnitude and Local Binary Pattern (LBP) bit, and densities of edge magnitude, LBP bit, color intensity and saturation. Each component of the feature vector produces a feature image. To obtain shape-invariant features, a detection window is partitioned into a set of small blocks called a partition, and many multi-scale partitions are generated by changing block sizes and partition schemes. The sum of each feature image within each block of each partition is computed to generate block features. The second mapping is from the block features to statistical features. The statistical features of the block features, such as, mean, variance, skewness, kurtosis and Hu moments, are computed on all partitions to form a feature pool. AdaBoost is used to select discriminative shape-invariant features from the feature pool. Experiments show that the proposed method has better generalization performance and less insensitivity to geometry transform than traditional methods.

Each component of the feature vector Fn can generate an independent feature image Fn, so D feature images (F1, …, FD−1) are produced from the original RGB image. ## Methods (continued): Shape-invariant features on partitions

<!-- original heading: "3. Shape-invariant features on partitions" (glued inside scrambled block S021) -->

<!-- src: S021, salvaged run (§3 lead-in; intact) -->
This section mainly presents the second step of mapping from block features to shape-invariant features. To improve computational performance, AdaBoost [19] with Haar-like features is used for smoke detection, but Haar-like features are shape-variant. To obtain shape-invariant features, statistical features are computed from block features on partitions of detection windows.

<!-- src: S024, salvaged run (Haar-like shape-variance) + S022 (intact continuation; column order was reversed on p5); "shapevariant" line-break join fixed -->
Each Haar-like feature can be specified by 5 parameters (c, x, y, wb, hb), which are feature type c, feature position (x, y), block width wb and block height hb, respectively. Sequential positions of the selected Haar-like features may encode a geometrical shape of an object. Fig. 3a shows a set of Haar-like features selected by an AdaBoost algorithm. For example, Haar-like features f1 and f2 capture the positions of eyes, Haar-like features f3 and f4, respectively encode the positions of nose and mouth, and other features encode the silhouette of the face. The sequential positions of the selected features actually encode the shape of the face. Different collections of selected Haar-like features encode different shapes. In other words, the Haar-like features are shape-variant. The shape-variant nature decreases the generalization performance of object detection when objects are rotated or deformed. For example, if the face image in Fig. 3a is rotated 30 degree around the image center, the selected Haar-like features may not detect the face at all. If Haar-like features are used for smoke detection, we may not obtain good generalization performances due to time-varying deformation of smoke shapes.

<!-- src: S023 — intact block -->
Several methods have been proposed to improve the performance of AdaBoost algorithms with Haar-like features. Pavani et al. [36] proposed an extension of Haar-like features for rapid object detection. Weights of blocks are optimized to maximize the ability of discriminating objects from clutter. He et al. [37] modified AdaBoost algorithms to propose a Topology Oriented AdaBoost (TOBoost) algorithm. The method can minimize the classification error of each selected feature at a faster convergence speed. Although the modified Haar-like features have better discrimination abilities and faster convergence speeds than traditional Haar-like features, they are still shape-variant.

### Partitions of detection windows

<!-- original heading: "3.2. Partitions of detection windows" (glued inside scrambled block S024) -->

<!-- src: S024, salvaged run (intact) -->
To obtain shape-invariant features, a feature extraction method is proposed to compute statistical features of block features on partitions of detection windows. As we can see from Fig. 3a, the small blocks of the Haar-like features learned by AdaBoost are irregularly located in a detection window, and the small blocks are usually prone to be located around the edges of the face. In other words, all the small blocks may not cover the whole region of the detection window. To eliminate the shape variant nature, all the small blocks are regularly re-positioned to completely cover the detection window (Fig. 3b), and we compute statistical features of the sum of each block, instead of computing the differences of the sum of neighboring blocks. The set of regularly distributed blocks is called a partition of the detection window.

<!-- src: S025 — intact block after glyph normalization; "multiscale" line-break join fixed -->
Two partition schemes are proposed in this paper. As shown in Fig. 4a, a detection window Bs with width ws and height hs is regularly partitioned into a set of small tiled blocks Bi (i = 0, …, Qj−1). The width and height of the tiled blocks are wb and hb, respectively. By changing wb and hb, we can obtain a lot of multi-scale partitions. The number Qj of blocks may be various for different partitions. Another partition scheme is shown in Fig. 4b. The detection window Bs is partitioned into a set of rectangular rings Ri (i = 0, …, Qj−1), which can be defined as the subtraction of two neighboring blocks Bi (i = 0, …, Qj−1), i.e., Ri = Bi − Bi+1. The horizontal and vertical thicknesses of rectangular rings are dh and dv, respectively. By changing dh and dv, we can generate a lot of partitions with multi-scale, and the number Qj of rings is also various for different partitions. A rectangular ring can also be called a ringed block. To obtain more partitions, we can also use overlapped blocks in Fig. 4a and Fig. 4b. The overlapped variants of partitions can increase the number T of partitions to form an over complete set of partitions. The two kinds of partition schemes are computationally efficient because the sum of a tiled or ringed block can be fast evaluated by integral images.

By applying the two partition schemes with different sizes, a lot of partitions SP = {WP0, …, WPT−1} are generated. These partitions are called multi-scale partitions and have scale-invariant properties due to varying sizes of blocks. That is very important for smoke detection since we do not know the size of smoke in videos. The j-th partition has Qj blocks, denoted as follows: WPj = {B0, …, BQj−1} (18). The block feature, which is actually the sum of a feature image Fn (n = 0, …, D−1) within a block Bi (i = 0, …, Qj−1) of a partition WPj (j = 0, …, T−1), can be rewritten as a uniform format Fn_{j,i} (j = 0, …, T−1; i = 0, …, Qj−1; n = 0, …, D−1).

The extraction of the shape-invariant features is summarized as follows. Fig. 5 shows the double mapping framework for partition based feature extraction with AdaBoost. The first mapping is from an original image f(x,y) to block features Fn_{j,i}. The feature images (F0, …, FD−1) are computed first according to the feature vector Fn formed by combining edges, color and LBP features of the image f(x,y). Then the sum of each feature image Fn (n = 0, …, D−1) is computed within each block Bi (i = 0, …, Qj−1) of each partition WPj (j = 0, …, T−1) to generate all the block features Fn_{j,i} (j = 0, …, T−1; i = 0, …, Qj−1; n = 0, …, D−1). The second mapping is from the block features Fn_{j,i} to the statistical features. The statistical features include the mean, variance, skewness, kurtosis and Hu moments. The statistical features are computed on all the partitions to form a large feature pool. Finally, an AdaBoost algorithm is used to select shape-invariant features from the feature pool.

### Implementation

The proposed method was implemented using Visual C++ to extract the shape-invariant features based on partitions. The size of the detection window is 24 × 24. The edge orientation is evenly divided into eight bins over 0° to 180°, i.e., K = 8. The magnitude is also quantized into eight bins, i.e., L = 8. The number of neighbors for the uniform LBP bit histogram is also eight, i.e., P = 8. So the dimension of the feature vector Fi are D = K+L+P+4 = 28, and 28 feature images are generated from an original image. Fifty partitions are created for the computation of the mean, variance, skewness and kurtosis. The feature number of the feature pool FPs is Ns = (K+L+P+4)×(T×3+1) = 28×(50×3+1) = 4228. Nine partitions are constructed for the Hu moments, so Nh = (K+L+P+4)×(T×7) = 28×(9×7) = 1764. So the total number Nf of features on each partition is Nf = Ns + Nh = 5992.

## Conclusion

<!-- original heading: "5. Conclusions" (glued inside scrambled block S054) -->

<!-- src: S054 (run, ends "…called a partition of the detection window. By") + S052 (exact cross-block seam "changing block sizes and partition schemes…") -->
Traditional smoke detection methods can achieve low training errors but generalization performances are less than satisfactory due to arbitrary shapes of smoke, intra-class variations, occlusions, and background clutter. To solve these problems, a double mapping framework is proposed to extract shape-invariant features based on partitions. First, a feature vector is formed by concatenating three histograms and four density features, and all the components of the feature vector generate a set of feature images. Second, a detection window is regularly partitioned into a set of small blocks, called a partition of the detection window. By changing block sizes and partition schemes, we can obtain a lot of multi-scale partitions. Third, the statistic features of the feature images are computed on each partition to generate a feature pool. The statistic features include mean, variance, skewness, kurtosis and seven Hu moments. Finally, an AdaBoost algorithm is used to select discriminative shape-invariant features from the feature pool and some additional techniques are used to further reduce false alarms. Several experiments were performed to evaluate robustness of these features. Experimental results show that the proposed method has quite better generalization performances and less sensitivity to image geometry transform than Haar-like feature based methods. By comparing the proposed method with other methods in the literature, the experimental results validate that the proposed method has better generalization performances than other methods. The proposed method can not only remove the shape-variant nature of Haar-like features but also achieve real time detection speed due to the use of Integral Images.
