### Smoke and non-smoke databases

To evaluate the discriminative capabilities of features based on partitions, two databases that include a training set and a testing set were created. The training set, containing 559 smoke images and 27,707 non-smoke images, was used to select shape-invariant features by the AdaBoost algorithm. The testing set, including 579 smoke images and 28,760 non-smoke images, was used for testing. Fig. 6 shows some training and testing images from the two sets.

### Implementation

The proposed method was implemented using Visual C++ to extract the shape-invariant features based on partitions. The size of the detection window is 24 × 24. The edge orientation is evenly divided into eight bins over 0° to 180°, i.e., K = 8. The magnitude is also quantized into eight bins, i.e., L = 8. The number of neighbors for the uniform LBP bit histogram is also eight, i.e., P = 8. So the dimension of the feature vector Fi are D = K+L+P+4 = 28, and 28 feature images are generated from an original image. Fifty partitions are created for the computation of the mean, variance, skewness and kurtosis. The feature number of the feature pool FPs is Ns = (K+L+P+4)×(T×3+1) = 28×(50×3+1) = 4228. Nine partitions are constructed for the Hu moments, so Nh = (K+L+P+4)×(T×7) = 28×(9×7) = 1764. So the total number Nf of features on each partition is Nf = Ns + Nh = 5992.

Traditional Haar-like features were also extracted for comparisons. The total number of the Haar-like features is 21,879.

Two strong classifiers with the same number of weak classifiers were learned from the two kinds of features. The first strong classifier selected 400 features from the large feature pool FP of partition features, which contains 5992 weak features. The number and types of selected features are shown in Fig. 7. As for component types of the feature vector Fi, the LBP bit histogram has the maximum number of selected features among the three histograms. Among the four density features, the bit density has the same maximum number of selected features as the intensity density. As for types of statistical features, the skewness feature has the maximum number. LBP features are dominant in the single mapped features while the statistical measures are dominant in the double mapped features. The total number of selected mean, variance, skewness and kurtosis features is 19+100+122+76 = 317, while the total number of selected Hu moments is 17+17+11+11+7+6+14 = 83. The second strong classifier also has 400 features learned from the feature pool of Haar-like features containing 21,879 weak features.

### Performance analysis

Experiments were performed on the testing set using the two strong classifiers. By changing the thresholds of strong classifiers, different detection rates and false alarm rates were obtained to plot curves of Receiver Operating Characteristic (ROC). Fig. 8 shows ROC curves for the partition features and the Haar-like features. As we can see, the ROC curve with the partition features is closer to the top-left corner than that with the Haar-like features. Although the feature pool of the partition features is smaller than that of the Haar-like features, the selected partition features have better generalization performance than the selected Haar-like features.

Experiments were done to validate the better performance of the modified uniform LBP codes than original uniform LBP codes. New codes are re-assigned to original uniform LBP codes, so the code re-assignment may change the bitwise sequence of LBP codes. The changes of bitwise sequences would destroy corresponding feature images and lead to inaccuracy computation of LBP bit density and LBP bit histogram. The code re-assignment decreases the generalization performance. As shown in Fig. 9, the features of the modified uniform LBP has better generalization performance than those of the original uniform LBP.

To evaluate the proposed method's sensitivity to geometry transform of images, the proposed method was compared with Haar-like feature based methods on two transformed sets. As shown in Fig. 10a, the central region of the original training images was cropped first, and then scaled to the original size of the training images, thus a new testing set was generated. Two transformed testing sets were generated from the training set by using scale factors 125% and 200%. As we can see, the statistic features on partitions have better generalization performances than the Haar-like features on the two transformed testing sets with the scale factors of 125% and 200%. In other words, the partition features are less sensitive to geometry transform than the Haar-like features. When the scale factor increases, the corresponding ROC curve is more far away from the top left corner of the chart. In other words, the detection performance is inversely proportional to the scale factor. Since smoke has different resolution images under different imaging parameters, the less sensitivity to geometry transform can improve the smoke detection performance.

### Smoke detection in videos

The proposed method was tested in three smoke videos. Fig. 11(a) and (b) show a video containing white smoke by burning dry leaves outdoors. We can see that possible smoke windows (red rectangles) were detected and exactly located in the real smoke regions. The proposed method seldom produced false smoke windows because the dry leaf smoke video has high image contrast. Fig. 11(c) and (d) show detection results in a cotton rope smoke video captured outdoors. Most of smoke windows (red rectangles) are detected and located in the real smoke region but there are a small number of false smoke windows (green rectangles) detected and located outside the real smoke region. The video has low image contrast and quality, so the proposed method detected more false smoke windows in the video than ones in the dry leaf smoke video. Fig. 11(e) and (f) illustrate a white smoke video near a waste basket. Most of the smoke windows were detected and located in real smoke regions.

Experiments were also performed in three non-smoke videos. Fig. 11(g) and (h) show a video in which there are students playing the basketball on a basketball yard. There is no false smoke window detected by the proposed method. Fig. 11(i) and (j) give a traffic video containing cars, trucks, and motorcycles. There is also no false smoke window detected. Fig. 11(i) and (j) show a video containing car lights in the night. There are a very small number of false smoke windows detected by the proposed method because of low image quality of the noisy video.

In order to reduce the number of false smoke windows, the ratio r(Bi) of each detected window Bi is defined as the maximum ratio of the common area of the detected window Bi and other detected window Bj to the area of the detected window Bi: r(Bi) = max_j Area(Bi ∩ Bj)/Area(Bi) (35), where ∩ denotes the intersection operation of two blocks, Area(Bi) is a function to compute the area of block Bi, and max() is a function to return the maximum value. If the ratio r(Bi) is less than a given threshold, the window Bi is considered as a false smoke window. As shown in Fig. 11(b), (c), (d), (f) and (k), false smoke windows (green rectangles) are automatically recognized by the ratio.

To give reliable fire alarms, dynamic analysis is applied before final decision. If the number of detected smoke windows is less than a threshold, it is reasonable for us to believe that current frame has no smoke. Even if the frame does have the number of detected smoke windows above the threshold, the proposed method should not give an alarm immediately. If smoke lasts for a short time, we can believe that it possibly is a false alarm and the short term smoke is considered unharmful.
