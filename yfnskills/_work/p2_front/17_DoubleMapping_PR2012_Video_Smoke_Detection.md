## Title

A double mapping framework for extraction of shape-invariant features based on multi-scale partitions with AdaBoost for video smoke detection

Feiniu Yuan

Pattern Recognition 45 (2012) 1186–1196. DOI: 10.1016/j.patcog.2011.08.008

## Abstract

Traditional methods for video smoke detection can easily achieve very low training errors but their generalization performances are not good due to arbitrary shapes of smoke, intra-class variations, occlusions and clutters. To overcome these problems, a double mapping framework is proposed to extract partition based features with AdaBoost. The first mapping is from an original image to block features. A feature vector is presented by concatenating histograms of edge orientation, edge magnitude and Local Binary Pattern (LBP) bit, and densities of edge magnitude, LBP bit, color intensity and saturation. Each component of the feature vector produces a feature image. To obtain shape-invariant features, a detection window is partitioned into a set of small blocks called a partition, and many multi-scale partitions are generated by changing block sizes and partition schemes. The sum of each feature image within each block of each partition is computed to generate block features. The second mapping is from the block features to statistical features. The statistical features of the block features, such as, mean, variance, skewness, kurtosis and Hu moments, are computed on all partitions to form a feature pool. AdaBoost is used to select discriminative shape-invariant features from the feature pool. Experiments show that the proposed method has better generalization performance and less insensitivity to geometry transform than traditional methods.

In this paper, a double mapping framework is proposed to extract partition based features with AdaBoost. AdaBoost [18,19] is an adaptive boosting machine learning algorithm and usually adopts Haar-like features that are shape-variant. To remove the shape-variant properties, a detection window is partitioned into a set of blocks at different scale, then statistic features are extracted on these multi-scale blocks, and finally AdaBoost is used to select shape-invariant features from these statistic features. Some motion based methods, such as [11], analyze dynamic behavior to discriminate smoke, so they may not detect slowly drifting smoke in videos. The method proposed in this paper can detect not only slowly drifting smoke in videos but also static smoke in images. Most of smoke detection methods, such as [16], prespecify features and then train a classifier. The proposed method uses a feature selection method to select discriminative features from redundant features and train a strong classifier at the same time. Since we do not know which features most stand for smoke, it is naturally believed that the feature selection method may probably obtain more robust features than the feature prespecification method.

This paper at least has two main contributions to video smoke detection. The first contribution is to propose the concept of multi-scale partitions of detection windows. The multi-scale partitions can eliminate the shape-variant properties of Haar-like features. Thus the generalization performance of the proposed method is greatly improved. The second contribution is to propose a double mapping framework for feature extraction with AdaBoost. The candidate features based on partitions are actually mapped twice from the original image. The final features are selected from the candidate features using AdaBoost. So partition based features are not the simple combination of features but the double mapping of features with AdaBoost. In addition, several new features are also proposed to characterize smoke, such as modified uniform LBP histogram, clamped edge magnitude histogram, LBP bit density and saturation density.

The double mapping framework is divided into two steps. The first step is to extract smoke features on small blocks from original frames of videos. The second step is to compute shape-invariant features on partitions that are composed of small blocks. So the structure of this paper is organized as follows. The two steps are presented in Sections 2 and 3, respectively. Experiments are described in Section 4. Finally, Section 5 concludes this paper.
