## Conclusion

Traditional smoke detection methods can achieve low training errors but generalization performances are less than satisfactory due to arbitrary shapes of smoke, intra-class variations, occlusions, and background clutter. To solve these problems, a double mapping framework is proposed to extract shape-invariant features based on partitions. First, a feature vector is formed by concatenating three histograms and four density features, and all the components of the feature vector generate a set of feature images. Second, a detection window is regularly partitioned into a set of small blocks, called a partition of the detection window. By changing block sizes and partition schemes, we can obtain a lot of multi-scale partitions. Third, the statistic features of the feature images are computed on each partition to generate a feature pool. The statistic features include mean, variance, skewness, kurtosis and seven Hu moments. Finally, an AdaBoost algorithm is used to select discriminative shape-invariant features from the feature pool and some additional techniques are used to further reduce false alarms. Several experiments were performed to evaluate robustness of these features. Experimental results show that the proposed method has quite better generalization performances and less sensitivity to image geometry transform than Haar-like feature based methods. By comparing the proposed method with other methods in the literature, the experimental results validate that the proposed method has better generalization performances than other methods. The proposed method can not only remove the shape-variant nature of Haar-like features but also achieve real time detection speed due to the use of Integral Images.
