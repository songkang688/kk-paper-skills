## Methods

This section mainly describes the first step of mapping from an image to block features. Smoke has important visual characteristics, such as low image contrast, low color saturation and small gradient magnitude, so edge, LBP and color features are combined together to propose a robust feature vector. Each component of the feature vector generates a feature image. The sum of each feature image within a block is computed to generate a block feature.

### Gradient based histograms

Gradients of an image, which are often used to detect edges of the image, provide important visual features for object detection. In recent years, there are a lot of gradient based features proposed in the field of object detection. The Scale Invariant Feature Transform (SIFT) [20] achieves an impressive performance on image registration and object detection. As a variant of SIFT, Histograms of Oriented Gradients (HOG) [21] are used for human detection. HOG can capture local gradient-orientation structures within an image but it is computed on a dense grid of uniform space over an image. Therefore, a high dimensional feature vector is produced to describe each detection window, resulting in expensive computation cost. Levi and Weiss [22] proposed the Edge Orientation Histogram (EOH) that is similar to HOG. This method employs gradient orientation information to extract the EOH feature. Chen et al. [23] integrated the EOH feature into the AdaBoost algorithm [18] for human detection.

Ojala et al. [25] defined the uniform pattern as one that has no more than 2 spatial transitions (U ≤ 2). They observed that uniform patterns are one of the fundamental patterns within image textures. The uniform patterns have P×(P−1)+3 different output values [26]. Mapping from an original pattern LBP_{P,R} to a uniform pattern LBPU2_{P,R} can be efficiently implemented with a lookup table of 2^P elements.

To improve the discriminative capability of LBP, several variants of LBP are proposed. A Local Ternary Pattern (LTP) [27] quantizes the gray-level differences of the neighboring pixels into a ternary value instead of a binary one. An Elongated Local Binary Pattern (ELBP) [28] uses an elliptic neighborhood instead of a circular one. An Improved Local Binary Pattern (ILBP) [29] compares the neighborhood pixels' intensity values with the local mean pixel intensity instead of the central pixel intensity. Nanni et al. [30] proposed Elongated Ternary Patterns and Improved Local Ternary Patterns. Guo et al. [26] proposed the Local Binary Pattern Variance (LBPV). In fact, this operator can be regarded as the integral projection along the variance axis. Liao et al. [31] proposed dominant local binary patterns for texture classification by regarding the first 80% most frequent patterns as dominant features. Jun et al. [32] proposed a Compact LBP (CLBP) by maximizing mutual information between features and class labels. The CLBP provides better classification performances with smaller number of codes.

Although there are many variants of LBP proposed in literature, they have not yet been proven effective for smoke detection. ### Color based features

There are many color models [33]. RGB (Red, Green, and Blue) is an additive color system based on the tri-chromatic theory. It is widely used in CRT (Cathode Ray Tube) based display systems, such as computer monitors. It is easy to implement but non-linear with visual perception. HSI (Hue, Saturation, and Intensity) is one of the most common cylindrical-coordinate representations of colors, which rearrange the geometry of RGB in an attempt to be more intuitive and perceptually linear. It is widely used in computer vision fields.

Two density features based on the HSI color model are proposed. The RGB color is converted into the HSI color. The intensity I and saturation S are used for calculation of features, while the hue H is ignored. ### Combination of features

Combination of different features can enhance the robustness of features. For example, to combine the strengths of SIFT and LBP, Heikkila et al. [34] introduced the Center-Symmetric Local Binary Pattern (CS-LBP) and used the CS-LBP as the local feature in the SIFT algorithm. Since there are three histograms, i.e., FEOH_i,k, FMag_i,l and FLBP_i,p, and four density features, i.e., FED_i, FBit_i, FI_i and FS_i for the block Bi, the three histograms and four density features are concatenated together to form a feature vector. Each component of the feature vector Fn can generate an independent feature image Fn, so D feature images (F1, …, FD−1) are produced from the original RGB image. The sum of a feature image Fn within the block Bi can be fast computed by the technique of Integral Images [19]. Once an integral image ii(x,y) is computed for a feature image, the sum of the feature image within the block Bi, specified by a bottom left point (x1, y1) and a top right point (x2, y2), is equal to ii(x1,y1)+ii(x2,y2)−ii(x1,y2)−ii(x2,y1). This allows us to compute the sum of rectangular areas in the image, at any position or scale, using only 4 lookups. Porikli [35] also uses the integral histogram technique to fast compute histograms. So histograms of block features can be efficiently computed by lookups in integral images.
