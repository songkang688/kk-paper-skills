# 不确定性、反例与不适用场景

本文件是这个 Skill 的诚实声明。它记录三类内容：证据薄弱的地方、与主流规则冲突的反例、以及明确不适用的场景。
**使用本 Skill 前应先读本文件**，否则容易把低置信度的推断当成硬规则。

---

## 一、证据最薄弱的地方：Discussion

**实际样本量是 1。**

| 状态 | 篇数 | 说明 |
|---|---|---|
| 真正独立成节且与 Conclusion 分开 | **1**（21，2011，独著，148 词） | 唯一可作证据的样本 |
| 作者写的局限性子节（在 Results 内） | 1（08，2019） | `F. Limitations of our method` |
| 作者在标题上声明合并 | 1（12，2023） | `4. Experiments and discussion` |
| **清洗者合成、原文不存在** | 1（11，2021） | **严禁引用为证据** |
| 无此节 | 18 | 这才是主流做法 |

**后果**：`section_playbook.md` §7 里那个"独立 Discussion 的最小骨架"是从三种单篇形态**反推的推断骨架**，其中"区分任务固有难点与方法自身缺陷""工程代价单列""不做意义升华"三步没有直接证据。用它的时候要知道这不是观察结果。

**唯一 confidence 为 high 的 Discussion 规则是"默认不写"**（18 篇支撑）。

## 二、与主流规则冲突的重要反例

### 反例 1：20 号同时违反多条规则，但它是 Tier A1 且提取质量最好之一

20_GP_IEEEAccess2017（一作 + 明确共同通讯，2017）的实际形态：
- Methods 整节只有 **1 个**目的从句（其他篇 5–11 个）
- Results 里几乎没有因果解释段
- 全篇只有 6 条图注，平均 7.2 词，**0 个子图标记**
- 没有章节路线句
- 贡献用序数散文而非列表

**它的"简约"不能用提取损坏解释**——该篇是全语料提取质量最好的之一。这是真实的写作形态。

**含义**：这套风格规则描述的是**语料的中心趋势**，不是作者的全部可能形态。当用户的论文更接近"复述既有算子 + 小改动"这类工作时，20 号的简约形态可能比主流形态更合适。

### 反例 2：21 与 17（两篇独著）是最不模板化的，却是作者身份最纯的

这两篇是全语料唯一的独著论文，零合作者混杂，但它们不符合多数结构规则：无独立 Related Work、无贡献列表、21 号的摘要是纯步骤枚举（`Firstly / Secondly / Thirdly / And fourthly`）、两篇都没有信息缺失式诊断。

**含义**：**结构 DNA 是 2016 年之后成型的。** 这两篇只能用于语言层取样，不能当结构原型。如果用户要求"最纯正的作者风格"，要先问清是要 2016 年后的成熟形态还是早期形态。

### 反例 3：36 号（2025，A1）是最晚期的 A1 论文，却在三处偏离

- Related Work 的定位段最弱，只说 `there remain some improvements to be achieved`，没说自己与谁不同
- 结论强度用 `competitive performance`（全语料最保守）
- 没有章节路线句

**单篇不足以成为趋势**，但它提示晚期写作可能变松。

### 反例 4：16 号（2018）打破 C5 的年代解释

局限与未来工作段有 9 篇，其中 8 篇在 2023–2026。16 号（2018）是唯一的早期例外，**而且它的局限写得比多数晚期论文更深**（误差在层间累积放大，需要反向传播纠错）。

**含义**：C5 的出现可能与"方法是否有可分析的失效机制"相关，而不只是投稿年份。这个竞争解释未解决。

### 反例 5：02 号的 CPA 模块消融无增益，作者主动说明原因

该篇的计数先验模块在三个测试集上没有带来提升，作者没有隐去这个结果，而是用 hedge 式因果句指出模块的设计目标是在图像级辅助分类，而这三个测试集**恰好不含类烟干扰物**（原文用 `The main reason may be that ...` 起头，以 `such as cloud` 收尾）。

这是"闭环在此处主动断开并说明原因"的范例，值得学习：**模块没效果时如实写出并给出条件性解释，不隐藏也不辩解。** 注意这个解释指向的是数据集构成而不是模块本身失效，属于可核验的条件性说明而非推脱。

## 三、六类混杂与已剔除项

完整清单见 `overgeneralization_blacklist.md`。这里只列最容易被误用的三项：

1. **被动语态密度**——纯年代效应。未控制时 Tier A1 的 Methods 被动密度 19.4/k，看起来远高于 A2 的 9.4，很容易被误读成"作者本人执笔更爱用被动"。**控制年代后 A1 降到 11.2，与 A2 的 8.8 接近，Conclusion 甚至反转。** 根源是 Tier A1 有 67% 的论文在早期，而 A3 与 Tier B 一篇早期的都没有。
2. **名词化绝对水平**——主题词汇效应。烟雾术语本身多 -tion/-ity 结尾。只保留章节间落差。
3. **缩写密度**——venue 效应。同主题内 IEEE 的 Conclusion 缩写密度是 Elsevier 的 2.4 倍。

## 四、无法解决的方法学限制

1. **年代与方法范式不可分离。** 按年份切（8/14）与按范式切（7/15）只差 1 篇论文，两组指标几乎逐项一致。所有标为"年代效应"的项都可能实际是范式效应。
2. **venue 与年代部分共线。** IEEE 烟雾论文 5/6 在晚期，Elsevier 烟雾论文 4/9 在早期。Conclusion 的目的从句密度差 3.4 倍（IEEE 11.2 vs Elsevier 3.3）无法归因。
3. **控制年代后的 Tier 比较在 A1 侧只有 2 篇**（07、36），只能作方向性参考。
4. **KSII 只有 2 篇**（30、31），该 venue 的所有差异不作判定。
5. **表格内容在全语料提取时普遍丢失**，无法覆盖表格内部排版、字体、配色。
6. **公式重建标记遍布 11 篇**，本 Skill 不对公式内容做风格判断。

## 五、明确不适用的场景

| 场景 | 原因 |
|---|---|
| 非计算机视觉/图像处理类论文 | 语料只覆盖烟雾、去雾、医学分割、少样本分割、超分五类视觉任务 |
| 中文论文 | 只建模英文写作 |
| 综述类论文 | 语料 22 篇全部是 journal 型方法论文，没有 survey |
| 会议论文的压缩格式 | 语料全部是期刊论文，31 号虽是会议论文的期刊扩展版但已按期刊形态写作 |
| 理论证明为主的论文 | 语料的方法论证以工程设计与实验为主，没有定理-证明结构 |
| 需要写 Discussion 独立章节且要求深度讨论 | 样本量是 1，只能给推断骨架 |
| 用户无法提供真实实验数据 | 事实性红线禁止编造数值 |

## 六、P5 自审记录（原句复制检查）

组装完成后做了一次机械检查：把语料 22 篇的英文词流切成 12-gram 建索引（157,082 条），再用同样方式扫描 `` 的全部 md 文件，找出连续 12 词以上与语料完全一致的片段。

**第一轮发现 11 处**，其中 4 处属实质违规——我把作者原句放在了"模板/示意句"位置，等于让使用者直接抄：
1. `Combinative methods can keep individual benefits ...`（`section_playbook.md` §4、`research_reasoning.md` RD2）→ 已改写为 `Hybrid designs are able to retain the respective strengths ...`
2. `Features by different methods have respective advantages, so it is natural ...`（`research_reasoning.md`）→ 已改为结构描述加两个改写示例
3. 颜色语义约定句（`visual_profile.md`）→ 已改为结构模板加改写示意
4. 数据集样例图注（`visual_profile.md`）→ 已改为结构模板加改写示意

另有两处做了处理：02 号 CPA 模块的 32 词因果句改为描述加片段引用；Methods 模板的 `Given an input feature map X ∈ R^{C×H×W}, we first ...` 改为 `For an input feature tensor ...` 以断开与语料的重合。

**第二轮复检剩 4 处，全部判定为可接受**，因为它们都不是作者写的文本：
- `(For interpretation of the references to colour in this figure, the reader is referred to the web version of this article.)` 出现在 3 个文件里——**必须原样引用才能让使用者识别并删除它**，这是 Elsevier 排版系统的插入句
- `The remainder of this paper is organized as follows` 出现在 Introduction 模板里——通用期刊模板句，已在黑名单中明确标注为非个人风格

**结论：`` 不含任何被当作模板提供的作者原句。** 白名单与黑名单里保留的原文片段都带明确的证据标注，属于可追溯性需要。

## 七、使用本 Skill 时最容易犯的五个错误

1. **凑密度指标。** 不要试图让目的从句达到"每千词几次"——那个数值受年代与 venue 影响，从 3.3 到 11.2 都出现过。只要保证每个模块前面有目的从句。
2. **把 11 号的 Discussion 当作者写法。** 它是清洗产物。
3. **用 02 号做引用密度结论。** 该篇清洗版本的括号引用数为 0，因为提取时把编号引用替换成了作者名叙述。
4. **把 Tier B 与 A3 的写法当作者本人风格。** 09/10（学生一作）的 Conclusion 目的从句密度为 0、非对称让步退化为 `comparable`；A3 三篇的 hedge 密度是各层最低，04 号改用 `We conjecture / We suspect / We think`。**这些差异恰恰是"作者本人 vs 学生执笔"的分界线。**
5. **在条件不满足时变形套用带条件的规则。** 例如给超分辨率论文硬写"传统传感器物理失效"式过渡，或给当代论文套 `at least N contributions`。
